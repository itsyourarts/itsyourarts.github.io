Why Use ShadowTrace URL Redirect Checker?

Whether migrating domains, auditing SEO backlink equity, verifying affiliate campaigns, or inspecting suspicious shortened URLs, ShadowTrace maps every server and client hop along the path.

🔍 Troubleshoot Redirect Loops & 404s

Diagnose NGINX, Apache .htaccess, PHP, Cloudflare Page Rules, Meta-Refresh, and JavaScript redirects. Catch broken 404 or 500 hops in the middle of a migration before visitors or bots hit a dead end.

📈 Protect SEO & PageRank Equity

Long redirect chains add round-trip latency and increase the risk of broken crawl paths. Consolidate multi-hop http → www → https → trailing-slash chains into a single clean 301 or 308 hop.

🎯 Audit Affiliate Links & Middle-Men

Spot every sub-affiliate network, attribution tracker (utm_*, clickid, aff_id), and cookie drop before the final merchant landing page — so you can partner directly with primary programs.

🛡️ Expand Tiny URLs Safely

Preview shortened links from bit.ly, is.gd, t.co, tinyurl, and QR codes without opening unknown sites in your browser tab. See TLS status, destination domain, and server headers first.

🤖 Crawler & Deployment Architecture

ShadowTrace Bot & Hybrid Architecture

Designed to run effortlessly on both Static GitHub Pages (zero backend) and Vercel / Self-Hosted Node.js.

🤖 ShadowTrace User-Agent

When running in Server or Edge Worker mode, ShadowTrace identifies itself by default as:

ShadowTrace/1.0 (+https://github.com/shadowtrace; Redirect Checker)

Webmasters can whitelist this User-Agent in WAF rules when auditing staging or production redirect chains, or switch User-Agent profiles in Advanced Options.

⚡ Hybrid Dual-Engine Design

1. GitHub Pages Static Mode: Works 100% in the browser with zero server setup! Uses CORS-enabled HTTP header chain inspection, Google/Cloudflare DNS-over-HTTPS, official IANA RDAP registries, and public shorteners.

2. Vercel / Node Deep Mode: Automatically activates when /api/health is present — unlocking custom User-Agent spoofing, millisecond socket timings, TLS certificate inspection, and HTML Meta/JS redirect parsing.

🚀 Deploy on GitHub Pages (Zero Config)

Push this repository to GitHub, open Settings → Pages, and deploy from main branch (root /) or via the included GitHub Actions workflow (.github/workflows/deploy-pages.yml). All relative paths work automatically on username.github.io/ShadowTrace/!

▲ Deploy on Vercel (Full Serverless API)

Import the exact same GitHub repository into Vercel with zero configuration changes. Vercel serves the static UI on its Edge CDN while automatically mounting api/trace.js and api/health.js as serverless functions with built-in SSRF protection.
