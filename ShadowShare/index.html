Privacy isn’t a feature. It’s the whole point.

ShadowShare is designed around direct sharing. In a production connection, files would travel peer-to-peer and would not be stored in cloud storage. Transfers use a temporary peer-to-peer connection. The signaling server only helps devices find each other; file contents do not pass through it.

Made to keep sharing in your hands
Good to know

Questions, answered.

Are my files uploaded anywhere?＋

No. File contents travel directly between the two devices using WebRTC. Our signaling server only exchanges connection details and never receives the files.

Can I really send files of any size?＋

The interface has no preset file size cap. In an actual transfer, available device storage, browser limits, and connection stability can still matter.

Does file transfer work on this preview?＋

Yes. Both people need to open ShadowShare in a modern browser. The sender must keep the tab open until the recipient finishes downloading.
