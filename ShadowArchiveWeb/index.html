    Formats, compatibility & limitations

    Reads public SHDW versions 1–4; creates chunk-authenticated SHDW 3/4 compatible with the Android app. Hidden-vault items/catalogs are a separate format and cannot be restored here. Normal mode is publicly decryptable, not private. Standard ZIP output is not password-encrypted. Password-encrypted ZIP input is not supported.

    Folder selection preserves file/subfolder paths; empty source folders may not be included by browser pickers. Browser folder saving needs supported File System Access APIs (typically Chromium desktop); otherwise download a verified ZIP or individual files. File selection never grants permission to remove your originals. No fixed 25 MB cap; output Blobs still consume browser storage/memory. Legacy SHDW 1/2 needs whole-file WebCrypto processing. This prototype is not independently security-audited.
