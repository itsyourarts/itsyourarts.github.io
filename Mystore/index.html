BEHIND THE STORE

About GodxShadow

One storefront for every release channel.

GitHub Releases poweredAuto sorting by extensionNo account required

GodxShadow reads the public release feeds of itsyourarts.github.io and My-Apps and turns them into one clean, neon storefront. Anything ending in .apk is filed under Apps, anything ending in .exe under Software, and every other file waits in Other.

Created by krishna UPX61, with a love for Android, Windows and a little neon.

An independent project, not affiliated with Google Play or Microsoft. Only install files you trust — this store does not verify the security of any release.

Two sources, one store

Files are listed from both release channels at once, with the source shown on every card.

Self-updating

Checks for new releases every 5 minutes while the page is open. Press Refresh any time.

Your device, your choice

Downloads are served directly by GitHub. Nothing passes through a third party.

How the store works

  1. Pick Apps for Android .apk files or Software for Windows .exe installers.
  2. Tap Download. The file is streamed with a live progress bar, then saved by your browser.
  3. If a download is blocked, use the direct link under the card to grab it from GitHub.
