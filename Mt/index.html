iframe mode — har count pe page ko ek chhote frame me load karta hai, jaise asli visitor. Page ka JS chalta hai, isliye jo bhi counter logic hai wo trigger hota hai. Sabse reliable.

ping mode — sirf HTML request bhejta hai, page render nahi hota. Bohot tez, par sirf tab kaam karega jab view server-side count hota ho.

Target = 0 rakho to jab tak Stop na dabao chalta rahega.

Important — per-IP dedupe ka case

Agar server ek IP ko 24 ghante me sirf 1 view ginta hai, to saare frames same IP se hain aur count nahi badhega. Test: 10 views chalao, phir video page khol ke count dekho. Na badhe to ping mode try karo.
